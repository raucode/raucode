# Raúl Figuera

**Desarrollo de software · Redes · Infraestructura**

[Portafolio](https://www.raulabz.online/) · [Currículum / PDF](https://www.raulabz.online/resume) · [Contacto](mailto:raulfigueracode@gmail.com)

Soy desarrollador con foco backend, basado en Brasil. Rust es mi herramienta principal; también trabajo en frontend, redes y operación de infraestructura. Me interesa entender el sistema completo: cómo se construye, cómo se conecta y cómo se mantiene funcionando.

Configuro y mantengo mi propio servidor, donde alojo aplicaciones y servicios. Desarrollo herramientas de TI y videojuegos, y fundé [RDX Entertainment](https://rdxentertainment.raulabz.online/) para darles una identidad propia a mis proyectos de juegos.

## En qué trabajo

- **Backend y arquitectura:** APIs, modelos de datos, autenticación, permisos e integraciones.
- **Productos e interfaces:** llevar la lógica del sistema a experiencias claras y utilizables.
- **Redes e infraestructura:** servidores Linux, virtualización, contenedores, identidad y monitorización.
- **Herramientas propias:** software para resolver problemas de operación y mantener continuidad entre proyectos y equipos.

## Del desarrollo a la operación

Mi servidor propio forma parte de mi trabajo diario: alojo servicios, preparo despliegues y observo su estado con **Zabbix y Grafana**. Esta práctica conecta mi experiencia de programación con los problemas reales de redes e infraestructura.

Uso **Codex y Claude** como asistentes para explorar soluciones, implementar funcionalidades, revisar código y documentar el trabajo. Second Brain aporta el contexto de los proyectos y ayuda a mantener continuidad entre herramientas y equipos.
